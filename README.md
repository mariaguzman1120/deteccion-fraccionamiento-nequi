# Deteccion de Fraccionamiento en Nequi

Este proyecto parte del problema de identificar posibles patrones de fraccionamiento transaccional en operaciones realizadas dentro del ecosistema de Nequi. El fraccionamiento ocurre cuando un monto que podria llamar la atencion por su valor, frecuencia o comportamiento se divide en multiples transacciones mas pequenas para reducir visibilidad y dificultar los controles de monitoreo.

Desde una perspectiva analitica, este problema no se limita a detectar transacciones aisladas, sino a reconocer secuencias, recurrencias y relaciones entre montos, tiempos, usuarios y contrapartes que, observadas en conjunto, podrian reflejar un comportamiento atipico o potencialmente riesgoso.

El reto principal consiste en diferenciar patrones legitimos de uso intensivo de aquellos comportamientos que podrian sugerir una estrategia deliberada de fragmentacion. Esto exige una aproximacion basada en datos que permita entender el contexto transaccional, caracterizar conductas y establecer criterios objetivos para priorizar casos de analisis.
